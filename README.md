## 小昼学习github
github协议
一般直接用MIT协议
MIT：保留协议副本即可，几乎随便用。最宽松、最常用，新手首选。
Apache：比 MIT 多了专利授权条款，企业项目常用。
BSD：类似 MIT，但多一条"不能用原作者名字做广告"。
GPL 系
GPL：改了代码必须开源，继承 GPL 协议。代表：Linux、WordPress、Git
LGPL：宽松版 GPL，新增自己的代码可以闭源。代表：很多 C/C++ 库
你的学习项目、个人项目、Demo 仓库，直接 MIT 就行，简单、省事、别人也能随便用。只有当你的项目特别在意"不能被私有化"时，才考虑 GPL。
